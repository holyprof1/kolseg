KOLSEG Design Services WordPress Theme

What is included:
- Theme folder with bundled CSS, JS, and image assets
- Editable homepage text and key images through the WordPress Customizer
- Standard page templates for front page, contact page, services page, and top projects page

Suggested setup:
1. Install the theme zip in WordPress and activate it.
2. Set Site Title to KOLSEG and Tagline to Design Services.
3. Create pages with slugs:
   - home
   - services
   - contact
   - portfolio
   - top-projects
4. Set the homepage to a static page using the Home page.
5. Use the Customizer to update hero text, phone numbers, and homepage images.
6. Use page content and featured images to update inner pages and service detail pages.
